# RenovateExample.jl: `julia-versioning`

Tests `julia` versioning (renovatebot/renovate#42995) through a `customManagers` regex on the `[compat]` entries of `Project.toml`, with the `julia-general-metadata` datasource.

See the [`master` README](https://github.com/stemann/RenovateExample.jl#readme) for all test branches and how to run them.
